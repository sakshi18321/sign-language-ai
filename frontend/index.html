How it works
🎯
Landmark Extraction
MediaPipe detects 21 hand keypoints (x, y, z). Runs server-side in Python for reliability, with browser-side as a bonus fast path.
🧠
Neural Network
63 landmark coordinates fed into a 4-layer dense network trained on synthetic+augmented ASL data.
⚡
FastAPI Backend
Landmarks sent to Python API running TensorFlow. Sub-50ms inference latency ly.
📝
Sentence Builder
Detected letters accumulate into words. Text-to-speech reads them aloud. Bidirectional: text → sign or sign → text.
